State-Space Modeling from First Principles

Imagine a drone flying from one building to another. Every second it must answer a simple question:

Where will I be one second later?

To answer that question, the drone does not need its entire history. It only needs a small set of variables that describe its current motion, such as position and velocity.

From those variables and the applied motor thrust, physics can predict the future motion. This idea is the foundation of state-space modeling.

In this note we will derive the state-space equations directly from Newtonian mechanics, understand the meaning of the matrices A, B, C, D, and see how they are used for simulation, prediction, estimation, and control.

Think of state-space as a compact mathematical description of a physical system that allows a computer to predict its future.

Step 1: Start with a Physical System

Consider a car moving in a straight line.

At any instant we care about:

  • Position p(t) in meters
  • Velocity v(t) in m/s

The smallest set of variables that completely describes the motion is

x(t) = [ p(t) ; v(t) ]

This is called the state vector.

Think of the state as the memory of the system. If you know the state now and the future input, you can predict future motion.

Step 2: Define the Input

Suppose the driver presses the accelerator.

u(t) = a(t)

where a(t) is acceleration.

SystemInput u
CarAcceleration
DroneThrust command
Robot armMotor torque

The input is usually known because we command it.

Step 3: Derive Motion from Physics

Take a small sampling interval Δt.

Position equation

p(k+1) = p(k) + v(k)Δt + 0.5 a(k)Δt²

Velocity equation

v(k+1) = v(k) + a(k)Δt

Replace a(k) by u(k).

Write both equations together

[ p(k+1) ; v(k+1) ] = [ p(k) + v(k)Δt + 0.5u(k)Δt² ; v(k) + u(k)Δt ]

Separate state terms and input terms:

[ p(k+1) ; v(k+1) ] = [ 1 Δt ; 0 1 ] [ p(k) ; v(k) ] + [ 0.5Δt² ; Δt ] u(k)

Now define

A = [ 1 Δt ; 0 1 ]
B = [ 0.5Δt² ; Δt ]

Therefore

x(k+1) = A x(k) + B u(k)
Notice that we did not guess A or B. They came directly from Newtonian kinematics.

Step 4: Understand Matrix A

Take Δt = 1 s.

A = [ 1 1 ; 0 1 ]

Multiply:

A x(k) = [ p(k)+v(k) ; v(k) ]

Interpretation:

  • new position = old position + velocity × time,
  • new velocity = old velocity.

A describes natural motion when no input is applied.

Step 5: Understand Matrix B

With Δt = 1:

B = [ 0.5 ; 1 ]

One unit acceleration produces:

  • +0.5 m change in position after 1 s,
  • +1 m/s change in velocity after 1 s.

B tells how strongly the input pushes each state.

Step 6: Numerical Example

Initial state:

x(0) = [ 0 ; 10 ]

Input:

u(0) = 2 m/s²

Prediction:

x(1) = A x(0) + B u(0)

Compute:

A x(0) = [ 10 ; 10 ]
B u(0) = [ 1 ; 2 ]

Add them:

x(1) = [ 11 ; 12 ]

After one second:

  • Position = 11 m
  • Velocity = 12 m/s

Step 7: Add a Sensor

Suppose a GPS measures position only.

y(k) = p(k)

In matrix form:

y(k) = [ 1 0 ] [ p(k) ; v(k) ]

Define

C = [ 1 0 ]

Then

y(k) = C x(k)

Meaning:

  • Position is measured.
  • Velocity is not measured.

Step 8: What is D and Why Is It Often Zero?

The general output equation is

y(k) = C x(k) + D u(k)

Think of two possible physical situations.

Case 1: Output changes only through system dynamics

Input = accelerator command, output = GPS position.

Accelerator command
        ↓
Acceleration changes
        ↓
Velocity changes
        ↓
Position changes

The position cannot jump immediately when the accelerator is pressed, so there is no direct path from input to output.

D = 0

Case 2: Output changes immediately with input

Input = voltage command, output = measured voltage.

Input voltage ───────────────▶ Output voltage
        (instantaneous path)

Here the output follows the input instantly, so

D ≠ 0

Example:

y(k) = 2u(k)

In that case C = 0 and D = 2.

Ask one question:

Can the output change instantly when the input changes?
  • No → D = 0
  • Yes → D ≠ 0

Step 9: Physical Meaning of the Block Diagram

The complete state-space model is

x(k+1)=Ax(k)+Bu(k)
y(k)=Cx(k)+Du(k)

Now include both paths from the input to the output.

Previous state x(k) ──▶ [ A ] ──┐
                                ▼
                              ( + ) ──▶ x(k+1) ──▶ [ C ] ──┐
                                ▲                           │
Input u(k) ───────────▶ [ B ] ──┘                           ▼
                                                           ( + ) ──▶ y(k)
Input u(k) ───────────────────────────────▶ [ D ] ──────────┘

Read it slowly

  1. x(k) is the current state of the system.
  2. A predicts how that state evolves naturally during one sample.
  3. u(k) is the external command.
  4. B converts the command into its effect on the states.
  5. The first (+) block forms the next state: x(k+1)=Ax(k)+Bu(k).
  6. C selects which states are visible to the sensor.
  7. D represents the direct path from input to output.
  8. The second (+) block forms the final output: y(k)=Cx(k)+Du(k).

Physical interpretation

  • A-path: motion caused by the previous state (inertia, momentum, stored energy, etc.).
  • B-path: motion caused by the applied input.
  • C-path: what the sensor can observe from the state.
  • D-path: any instantaneous effect of the input on the output.

Car example (GPS position)

  • Input: accelerator command.
  • Output: GPS position.
  • The accelerator affects position only through acceleration and velocity.
  • Therefore the direct path is absent, so D=0.

Voltage measurement example

  • Input: commanded voltage.
  • Output: measured voltage.
  • The sensor reads the input immediately.
  • Therefore the direct path exists, so D≠0.
The block diagram is simply a picture of the two state-space equations. The upper path creates the state dynamics, while the lower path represents any instantaneous input-to-output feedthrough.

Step 10: Final State-Space Model

x(k+1) = A x(k) + B u(k)
y(k) = C x(k) + D u(k)

with

A = [ 1 1 ; 0 1 ] B = [ 0.5 ; 1 ] C = [ 1 0 ] D = 0

This is the complete mathematical model of the car.

Step 11: MATLAB Meaning of ss

In MATLAB we write:

ss means state-space object. MATLAB stores the matrices and treats them as one dynamical system.

Think of sys as a digital twin of the car.

Step 12: Continuous to Discrete (c2d)

Continuous physics:

ẋ(t) = A_c x(t) + B_c u(t)

Computers work at discrete sampling instants, so MATLAB converts the model using c2d.

c2d means “continuous to discrete”. It computes the exact discrete matrices for the chosen sampling time.

Step 13: Simulate the Model (lsim)

lsim means “linear simulation”. MATLAB repeatedly applies the state equation and computes the output at every time step.

Step 14: Why State-Space is Powerful

MethodInternal states visible?
Transfer functionUsually no
State-spaceYes

State-space lets us estimate hidden quantities such as velocity, acceleration, orientation, battery state, and many other variables.

Step 15: Where Estimation Begins

Real systems are not perfect. Wind, vibration, friction, and sensor errors introduce uncertainty.

x(k+1) = A x(k) + B u(k) + w(k)
y(k) = C x(k) + D u(k) + v(k)

where w(k) is process disturbance and v(k) is sensor noise.

State-space modeling provides the physics. Estimation methods such as the Kalman filter use this model to recover the most likely true state from noisy measurements.

Key Takeaways

  • State-space is physics written in matrix form.
  • A describes natural evolution.
  • B describes input influence.
  • C describes what we can measure.
  • D describes direct input-to-output feedthrough.
  • ss creates the mathematical system.
  • c2d converts continuous physics to discrete-time form.
  • lsim simulates the response of the model.
  • This model is the foundation for modern estimation and control algorithms.
